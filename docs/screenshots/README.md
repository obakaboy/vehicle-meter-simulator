# スクリーンショット配置ガイド

このフォルダに次の3枚をPNG形式で保存します。画像はまだ同梱していません。アプリ画面を撮影し、README冒頭の「画面」セクションへ掲載してください。

| ファイル名 | 撮影する画面 | 操作例 |
| --- | --- | --- |
| `meter.png` | メイン画面。速度・燃料・ACC・走行モードが分かる状態 | PでON → Wで30 km/h以上へ加速 → CでACC開始 → Wを離す |
| `drive-summary.png` | 今回の距離・時間・平均燃費 | 少し走行してPでOFFにし、Summaryを撮影 |
| `drive-history.png` | 複数の履歴と上部の統計 | PでON→走行→PでOFFを2～3回行い、Summaryを閉じ、電源OFF中にH |

`+` / `-`でACCの目標速度、Mで走行モード、Tで距離表示を切り替えられます。スクリーンショットに写っている機能や値と、説明文を合わせてください。

アプリのウィンドウ部分だけを切り取り、読みやすい解像度で保存します。発表スライドから画像を切り出す必要はありません。新しいビルド先で起動すれば、その実行ファイルの隣に新しいDBが作られるので、撮影用のシミュレーション履歴を用意できます。DBそのものは公開しません。

画像を配置したら、ルートREADMEの「画面」セクションの案内・表・HTMLコメントを、以下に置き換えます。画像が存在する前に有効化するとリンク切れになるため、3枚を置いてから変更してください。

```markdown
### メーター画面

![速度計、燃料、ACC、走行モードを表示するメーター画面](docs/screenshots/meter.png)

### Drive Summary

![電源OFF時に今回の走行距離、時間、平均燃費を表示](docs/screenshots/drive-summary.png)

### Drive History

![保存した走行履歴と走行回数、総距離、総時間、平均燃費、最長距離](docs/screenshots/drive-history.png)
```
